# Release v2.6.4 - About Command

## Summary

This patch release adds an `about` command for quick project metadata and credits.

## What's Changed

### Added `about` command

`kryten about` now prints:

- Project name
- Current version
- Credits
- Project URL
- A thank-you to the people who make Cytu.be's Channel-Z excellent

## Version

- `kryten-cli` version: `2.6.4`
